# what do you mean there is a test tomorrow?

An intelligent, aesthetics-focused study and prep scheduler.

## Features
- **Smart Scheduling**: Automatically calculates exactly how many hours you need to study per day to reach your total estimated prep time before the deadline.
- **Strict Boundaries**: Enforces a strict 5-hour daily limit to prevent burnout.
- **Multiple Views**: Supports List View, Table View, and a Full Calendar View.
- **Dynamic Task Management**: Tasks stay firmly in your daily plan when completed, showing a satisfying strikethrough without messing up your schedule.
- **Course & Folder Organization**: Categorize your tasks by course/folder with custom colors.
- **Warm Beige Theme**: A sleek, modern, light theme with glassmorphism panels.
- **Import / Export**: Easily export and backup your schedule as JSON.

## Setup
Simply open `index.html` in your web browser. No local server required! All data is saved directly in your browser's local storage.
